
# isaac-tools

Minimal single-page React app to browse and search items from The Binding of Isaac.

## Quick Info

- Built with React + Vite
- Data: served custom JSON in `/public`
- Main components: `Header`, `SearchBar`, `ItemList`, `ItemCard`, `Footer`

## Run

```bash
npm install
npm run dev
```

Open the URL shown by Vite or use the GitHub deployment [URL](https://vegatf.github.io/isaac-tools/).
